# Changelog

## [0.1.0]

### Added

- Initial public KAVP framework release.
- Core policy representation (PolicyIngestion, PolicyParser, GraphBuilder).
- Constraint propagation engine (ConstraintPropagation).
- Federated orchestration interfaces (FederatedOrchestrator, DemoNodeFactory).
- Audit logging (AuditLogger).
- GDPR typed policy graph extension (kavp.gdpr).
- PyPI packaging with src layout.
- Minimal CLI (`kavp --version`).
